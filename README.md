## The fortune

> You will meet a tall, dark stranger: your own error log at 3 a.m., with 214 warnings you swore were fixed.

## How it works

`main.py` (Python 3 standard library only, no third-party packages) writes that
single line — 106 characters — to `/output/entry.txt`, guarded by asserts that
the text is exactly one line of 1–200 characters.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
